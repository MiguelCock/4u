# Admin Guide / Guía del administrador

A step-by-step guide for administrators using the app to add and manage campus data (places, buildings, anchor points, and connections).

Una guía paso a paso para los administradores que usan la aplicación para agregar y gestionar los datos del campus (lugares, edificios, puntos de anclaje y conexiones).
