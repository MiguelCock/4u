# Eyes4U: cómo prepararte para el evento

Gracias por participar. Eyes4U guía a personas con discapacidad visual dentro del campus, usando el GPS y la cámara del teléfono para saber con más precisión dónde estás.

**Funciona solo en teléfonos Android.** Si tienes iPhone, te emparejaremos con alguien que tenga Android.

## Antes del evento, en casa y con Wi-Fi

1. **Descarga la aplicación** desde este enlace. Pesa unos 66 MB, por eso es mejor hacerlo con Wi-Fi:

   **https://github.com/MiguelCock/4u/releases/latest/download/app-release.apk**

2. **Ábrela para instalarla.** Android puede avisar de que viene de fuera de la tienda. Toca **Configuración**, activa **Permitir de esta fuente** para tu navegador, vuelve atrás y toca **Instalar**.
3. **Abre Eyes4U** una vez y acepta los permisos que pide:
   - **ubicación**, para guiarte;
   - **cámara**, para reconocer el lugar (las fotos solo se usan para corregir tu posición);
   - **micrófono**, para decir a dónde quieres ir.

**No crees una cuenta.** El día del evento te daremos una tarjeta con tu correo y contraseña.

## El día del evento

1. Entra con el correo y la contraseña de tu tarjeta.
2. Elige el destino que te indiquen. La aplicación elige el punto de partida más cercano a ti.
3. **Sostén el teléfono derecho, con la cámara hacia adelante,** a la altura del pecho. Así reconoce mejor el lugar.
4. Sigue las indicaciones habladas. Si te pierdes, detén el recorrido y vuelve a empezarlo desde donde estés.

## Datos y batería

- **Datos:** durante un recorrido la aplicación envía una foto cada pocos segundos, unos **180 MB por hora**. Si tu plan de datos es pequeño, usa la Wi-Fi del campus.
- **Batería:** la cámara y el GPS gastan bastante. Llega con el teléfono cargado.

## Si algo falla

Busca a la persona que organiza. Ella puede darte otra cuenta, o emparejarte con alguien.

Hay más detalles en la [guía del usuario](../user-guide/es/README.md).
